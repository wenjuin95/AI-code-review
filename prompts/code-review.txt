- Bugs
- Incorrect logic
- Security vulnerabilities
- Authentication/authorization problems
- Input validation problems
- Data loss
- Race conditions

- Error handling problems
- Performance problems
- API misuse
- Breaking changes

- Personal coding style

Short description.

description:
Explain why this is a problem.
